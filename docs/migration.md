## 明确改变了行为的修复

1. **用户 ID 的标签泄漏。** 原动态分组将 `Src IP + Dst IP + label` 拼成用户 ID。现仅使用通信实体字段；自适应策略的选择只在训练阶段进行，评估不再读取测试标签选择分组。
2. **测试阶段的预处理拟合。** 原测试路径也执行标签驱动的 IV 筛选并更新传入元数据。本版在训练阶段冻结分组、数字列、特征顺序、IV、标准化器；测试阶段只变换，缺失训练特征报错。
3. **列类型误识别。** 原代码先尝试时间转换，可能把数字列当成时间。本版明确区分标识、标签、时间与数字流量列，统一处理 NaN/Inf，不再静默补造标签和时间。
4. **标签列分支错误。** 原存在 `flag` 时仍可能访问 `Label`。本版显式识别标签；拒绝缺失、空标签和非二元数字。文本标签 Normal/Benign 为正常，其余非空文本为异常。
5. **时间顺序。** 原滚动、差分在排序前计算；现先按用户和时间稳定排序，再计算。无有效时间时直接报错，不再用持续时长累加或行号冒充绝对时间。
6. **IV 数值稳定性。** 原纯类别分箱可能产生无穷 IV，且遍历时删除列表会跳过特征。现用 0.5 平滑和独立筛选列表。默认下限保留 0.02；论文提及高 IV 剔除但未给出可核验阈值，原代码也没实现，故 `iv_max` 默认 null，供显式设定。
7. **前向传播副作用。** 原模型直接重写 `data.x`，重复调用同一个图会再次做特征门控。现克隆输入后处理；保留模型参数与主要运算结构。
8. **图错误处理。** 原图分支会截断越界边，或把计算异常吞掉并返回零特征。现对无效输入报错，避免训练在图分支失效时继续产生结果。
9. **单类别指标。** ROC AUC 不可定义时输出 JSON null；分类报告始终给出两个类别，不会因目标名称长度不符而崩溃。
10. **重复运行与输出。** 显式命令分别执行训练与评估；输出目录不得包含旧文件。保存有效配置、特征、训练历史、环境版本与数据哈希。

## 与论文／原代码的边界

- 论文定义时间点异常比例超过整体比例即为异常；原代码实际采用“任一异常即异常”。默认 `label_rule="any"` 保留原代码行为；`"ratio"` 采用比例规则，参考值冻结为训练集比例，避免测试集统计参与定义。两者不可混称同一实验协议。
- 图分支实际为 **三层 GCN + 一层双头 GAT**，而非纯 GAT；保留实际结构。配置中原 `gcn_layers`、`gat_heads` 等未参与构造，现删除，结构在模型代码中明确。
- 原所谓难度自适应模块实际只有线性层；本版保留，但不宣称实现了动态课程或难度调节。
- 原训练实际逐用户处理，`batch_size=4` 无效；本版删除该参数，没有改变为批量图训练。
- 保留供给代码中已有的 Monte Carlo 异方差 Focal Loss 和 logistic-normal 推断。论文只描述 Focal Loss 与不确定性输出，不能仅凭论文证明此数值目标就是历史实验所用版本。
- 保存最低训练损失模型；本次未擅自增加验证集、提前停止或阈值搜索。要研究泛化效果，应另行制定验证协议。
- 新划分工具为去重后按流行分层随机划分；与旧脚本按用户抽样等变体并不等价，未恢复论文历史数据划分。相同原始流不会同时进入两个新划分，但同用户和同时间可跨集合出现。
- 未搬入未经核验的基线实现及旧结果 CSV；未重新执行论文全量训练、30 次重复实验或统计显著性分析。应在本版协议下重新生成完整结果。

这些变化可能显著改变指标，尤其是移除用户分组中的标签泄漏。发布时应将其标为整理及修正版，避免将历史高分作为当前代码的运行结果。
